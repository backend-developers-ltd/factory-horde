# Behavioral acceptance controls

This development-only factory emits working, non-persistent or broken to-do CLIs. The public hotkey's SHA-256 integer modulo three selects the variant, recorded in factory logs. Require all three variants in an acceptance cohort. The deliberately inaccurate README in defective controls tests whether execution evidence outweighs claims. This fixture makes no model calls; each resulting application is evaluated once by the production behavioral judge.
